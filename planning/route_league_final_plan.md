# 차량용 경로 경쟁 서비스 기획서

현대자동차그룹 차량용 앱 개발 공모전 출품 기획안
작성 기준일 2026년 10월 31일

이 서비스는 같은 도로 경로를 이용하는 운전자들이 차량의 연비·전비 기록을 비교하고, 자신의 개선을 확인하는 Pleos Connect 앱이다. 첫 서비스는 반복 출퇴근 운전자를 대상으로 운영한다. 주행 중에는 데이터를 자동 기록하고 주차 후에 결과와 보상을 제공한다. 여행자의 경로 수집과 커뮤니티는 같은 기록 기반 위에서 확장한다.

초기 운영은 20명 검증과 최대 100명 시범 서비스로 구성한다. 경쟁은 같은 차종과 비교 가능한 조건의 경로별 리그로 운영하며, 속도와 도착 시간에는 순위 점수를 부여하지 않는다. 4주 시즌, 주간 미션, 성장 등급과 수집 배지로 반복 참여의 재미를 만든다. 기본 목표 달성 보상과 상위권 추가 상품을 함께 제공한다. 보험료 혜택은 데이터 검증 이후 추진할 제휴 과제로 둔다.

현재 단계는 기획이며, 아래 개발 일정·사용자 지표·예산은 실행 목표와 산정 가정이다. 실차 성능, 사용자 확보 실적, 제휴 계약을 확보한 것으로 표현하지 않는다.

## 1 서비스 소개

**앱명:** ______________________________

같은 길을 다니는 운전자들이 효율 리그에 참여하고, 주간 미션과 배지 수집으로 자신의 경로를 성장 기록으로 만드는 차량용 앱이다.

사용자는 익숙한 출퇴근길을 자신의 도전 코스로 등록한다. 평소처럼 운전한 뒤 주차하면 기록 판정, 주간 순위, 미션 달성, 새 배지를 차례로 확인한다. 같은 길에서 실력을 쌓는 감각과 자신의 기록장을 꾸미는 재미를 제공한다. 여행에서는 이미 다녀온 경로가 수집 카드로 남는다. 초기에는 출퇴근 경험을 완성하고, 여행 기능을 순차적으로 추가한다.

## 2 기획 배경과 고객 문제

### 반복 출퇴근 운전자의 문제

차량에 평균 연비가 표시되어도 오늘의 변화가 운전 방식, 정체 또는 다른 도로 조건 때문인지 이해하기 어렵다. 누적 평균만으로는 같은 출퇴근길에서 지난 기록보다 나아졌는지 판단하기도 어렵다. 운전자는 자신의 일상 경로에 연결된 피드백과, 꾸준히 참여할 만한 성취를 필요로 한다. 이 니즈의 강도는 초기 인터뷰와 사용 실험으로 검증한다.

이 서비스는 경로를 고정하고 비교 가능한 기록을 모아 개인 기준과 다른 운전자의 분포를 보여준다. 한 번의 높은 기록보다 주간 기록의 일관성을 평가하고, 상위권이 아니어도 개인 목표를 달성하면 기본 보상을 받을 수 있도록 한다.

### 경로를 경쟁 단위로 사용하는 이유

경로는 사용자가 실제로 이동하는 순서와 방향이 있는 도로의 연결이다. 같은 길의 기록을 반복해서 쌓을 수 있고, 기록이 좋아지거나 나빠진 맥락을 설명하기 쉽다. 경로의 시작과 끝, 진행 방향, 도로 일치 여부를 정의해 비교 대상을 제한한다.

같은 경로라는 사실만으로 조건이 같아지지는 않는다. 차량, 교통, 기온 등 측정 가능한 조건을 함께 표시하고 비교 집단을 구분한다. 충분한 비교 표본이 없으면 개인 기록을 제공하고 공개 순위와 순위 보상을 열지 않는다.

### 초기 고객과 확보 경로

첫 고객은 Pleos Connect에서 필요한 데이터 접근이 가능한 차량을 사용하고, 주 3일 이상 비슷한 출퇴근 경로를 이용하는 운전자다. 같은 생활권의 직장인 모임과 차종별 동호회에 참여자를 모집하는 계획으로 시작한다. 접촉 가능한 커뮤니티와 지원 차량 수를 확인한 후 운영 경로를 확정한다. 현재 확보된 모집 채널이나 참여자는 없다.

첫 20명은 사용성·데이터 가용성 검증에 참여한다. 같은 경로와 차종의 비교 집단을 구성할 수 있을 때 최대 100명으로 확대한다. 실차 또는 허용된 테스트 배포 환경을 확보하지 못하면 에뮬레이터 시연과 사용자 인터뷰를 진행하며, 이를 실제 주행 검증 실적으로 계산하지 않는다.

여행·드라이브 이용자는 두 번째 고객군이다. 다녀온 경로를 보관하고 공유하려는 수요를 경로 여권으로 검증한 뒤 커뮤니티를 확대한다.

## 3 주요 기능과 차량 특화 가치

| 기능 | 사용자에게 제공하는 가치 | 차량 데이터와의 연결 |
| --- | --- | --- |
| 자동 주행 기록 | 별도 조작 없이 평소 이동이 기록됨 | 차량 속도, 위치, 주행 세션, 연비·전비를 연결 |
| 내 경로 결과 | 같은 길의 과거 기록과 비교해 변화 확인 | 동일 경로의 소비량과 측정 조건을 함께 표시 |
| 경로별 시즌 리그 | 익숙한 길에서 주간 순위와 대표 배지에 도전 | 차종·동력계·진행 방향·시간대 등의 비교 집단 구성 |

| 경로 여권과 수집 카드 | 다녀온 길의 배지와 카드를 모아 기록장 구성 | 실제 통과한 경로와 방문 기록을 저장 |
| 주차 후 결과와 보상 화면 | 기록 공개와 미션 완료 연출로 성취 확인 | 주행·주차 상태에 맞춰 화면 기능 전환 |

스마트폰 위치 정보만으로 만들 수 있는 방문 인증에 더해, 차량이 제공하는 에너지 효율 정보와 주행 맥락을 같은 기록에 결합한다. 이 결합을 앱의 중심 경험으로 삼는다. 차량 데이터가 기록 조작을 완전히 막아준다고 주장하지는 않는다.

### 경쟁 규칙

경로 ID는 시작·종료 측정 경계, 진행 방향, 도로 연결, 버전으로 관리한다. 역방향은 별도 경로이며, 우회·중도 진입·일부 통과 기록은 동일 경로 경쟁에 넣지 않는다. 초기 경로는 운영자가 선정하고, 경로 중복 생성과 검증되지 않은 구간 등록은 제한한다.

비교 집단은 우선 같은 차종·동력계·경로·방향·유사 시간대로 구성한다. 충분히 기록할 수 있는 조건만 분류에 사용하며, 기온·정체 정보를 확보하면 추가한다. 탑승 인원·적재량·타이어·공조 사용 등 완전히 통제하지 못하는 차이는 남는다. 결과는 해당 집단의 주행 효율 비교이며, 운전 실력의 절대적인 평가로 표시하지 않는다.

시범 운영에서 리그 개설 기준은 비교 가능한 참여자 10명 이상으로 설정한다. 참여자는 평가 주간에 유효한 평소 주행 3회 이상이 있을 때 주간 순위에 포함한다. 이는 초기 운영 기준이며, 기록을 늘리려고 추가 운행하도록 권유하지 않는다. 조건이 부족하면 개인 기록과 여행 기록을 계속 제공한다.

연비는 L/100km, 전비는 지원 API의 단위를 확인한 뒤 Wh/km 등 소비량 중심 단위로 변환해 처리한다. 내연기관과 전기차 기록을 하나의 절대 수치로 순위화하지 않는다. 주간 순위는 각 참여자의 유효 기록 소비량 중앙값으로 정하고, 소비량이 적을수록 높은 순위로 표시한다. 측정 오차 범위 안의 차이는 공동 순위로 처리한다. 공동 순위의 보상은 경계 순위에 걸친 대상자에게 해당 상품의 총액을 균등 배분하는 등 사전 공지한 방식으로 예산 안에서 처리한다.

개인 개선도는 같은 차량·경로의 비교 가능한 기준 기록 5회 이상의 중앙값을 사용한다. 기준 기록은 시즌 시작 전에 확정하고 시즌 중 임의 변경을 막는다. 소비량이 8.0L/100km에서 7.2L/100km로 낮아지면 10% 개선으로 표시한다. 비교 조건 차이가 크거나 측정 오차보다 변화가 작으면 개선 여부를 확정하지 않는다. 개선도는 피드백과 기본 목표에 활용하고, 높은 금액의 추가 상품은 검증된 효율 리그에서 배정한다.

도착 시간은 기록의 맥락을 설명하는 정보로만 제공한다. 빠른 도착, 많은 주행거리, 반복 통과 횟수에 추가 경쟁 점수를 주지 않는다.

### 시즌과 미션으로 만드는 게임 경험

게임 경험은 ‘내 경로 선택 → 평소 이동 자동 기록 → 주차 후 결과 공개 → 미션 달성과 배지 획득 → 다음 주 도전’의 흐름으로 구성한다. 경로별 경쟁과 개인 성장을 함께 보여주되, 경험치가 효율 순위를 바꾸지는 않는다.

| 요소 | 운영 방식 | 사용자가 느끼는 재미 |
| --- | --- | --- |
| 4주 시즌 | 같은 비교 집단에서 주간 순위를 갱신하고, 시즌이 끝나면 다음 시즌 기록판을 새로 시작 | 다시 도전할 기회와 시즌별 기록 보관 |
| 주간 대표 배지 | 유효한 주간 효율 순위 1위에게 경로·주차가 표시된 배지 지급, 공동 1위는 함께 지급 | 내가 다니는 길에서 얻는 상징적인 명예 |
| 개인 미션 | 기준 기록 완성, 주간 효율 유지, 검증 오차를 넘는 개인 기록 개선 등 | 순위와 무관하게 달성할 수 있는 목표 |
| 성장 등급 | 미션 경험치로 도전자·숙련자·마스터 등급과 프로필 테두리 해금 | 누적 성장이 보이는 프로필 |
| 경로 수집 카드 | 기존 여행에서 통과한 경로를 카드로 보관하고 테마별 기록장에 배치 | 다녀온 길을 모으고 공유하는 즐거움 |

첫 시범 운영의 경험치는 미션 종류별 주 1회 10점, 주간 최대 30점으로 설계한다. 누적 0점은 도전자, 30점은 숙련자, 60점은 마스터로 표시하며 이후 등급은 사용 결과에 따라 설계한다. 경험치는 효율 순위·기프티콘 금액·보험 혜택에 영향을 주지 않는다. 기본 보상은 기존 목표 달성 조건으로, 추가 상품은 검증된 리그 순위로 판단한다.

미션은 실제 평소 이동에서 충족할 수 있는 조건으로 제공한다. 예를 들어 ‘내 기준 기록 완성’은 비교 가능한 기존 주행 5회가 모였을 때 한 번 완료되고, ‘이번 주 효율 지키기’는 유효한 주간 소비량 중앙값이 개인 기준을 유지하거나 개선했을 때 완료된다. 측정 오차를 넘는 개선이 확인되면 ‘나의 기록 갱신’ 배지를 지급한다. 미션별 달성·경험치 지급은 한 번만 처리하고, 반복 주행으로 경험치를 추가 획득하지 못하도록 한다.

시즌은 순위와 시즌 미션만 새로 시작하고, 누적 경험치·성장 등급·획득 배지·경로 여권은 보존한다. 배지는 실제 도로의 소유권이나 독점권을 뜻하지 않는다. 쉬는 날에도 누적 성취가 사라지지 않으며, 매일 접속하거나 운전해야 유지되는 연속 출석 보상은 두지 않는다.

주차 후 결과 화면은 소비량과 비교 조건을 먼저 보여준 뒤 순위 변화, 미션 완료, 배지 획득을 짧게 연출한다. 사용자는 연출을 건너뛸 수 있다. 주행 중에는 경쟁 알림이나 보상 효과를 표시하지 않는다. 차량 아바타와 기록장 꾸미기는 후속 기능으로 두고, 외형 변경이 순위나 측정 결과에 영향을 주지 않도록 한다.

### 기록 자격과 운전 중 사용

기록이 순위에 들어가려면 경로 일치, 측정 범위 일치, 데이터 연속성, 적용 가능한 제한속도 정보 등 필수 조건을 충족해야 한다. 속도 초과가 확인되거나 데이터가 부족하면 해당 기록을 순위·보상에서 제외하고 이유를 표시한다. 측정 오차 처리를 위한 기준은 사전 실험으로 정하며, 임의의 과속 허용 폭을 보상 규칙으로 만들지 않는다.

위험을 피하기 위한 급제동을 일괄 감점하지 않는다. 지나친 저속 주행, 공조 중단, 차간거리 축소처럼 효율 수치를 높이기 위한 위험한 행동을 안내하지 않는다. 이 앱의 기록 자격 판정은 법적 위반 판정이나 모든 위험 행동의 부재를 인증하는 기능이 아니다.

운전 중에는 자동 수집을 수행하고 순위·상품·커뮤니티 화면을 표시하지 않는다. 신호대기 중 속도가 0인 상태를 주차로 간주하지 않으며, 플랫폼의 주행 제한 상태와 지원되는 주차 상태 정보를 함께 확인한다. 상태를 확인할 수 없을 때는 상호작용 화면을 잠근다. Pleos의 운전자 주의 분산 및 콘텐츠 안전 가이드에 따라 앱 유형과 주행 중 백그라운드 동작 허용 범위를 확인한다. [S4]

### 보상과 경로 여권

기본 보상은 사전 등록된 시범 참여자에게 월 1회 제공한다. 예시 조건은 비교 가능한 주간 평가 중 2주에서 개인 기준 소비량을 유지하거나 개선하고 기록 자격을 충족하는 것이다. 유효성 확인만으로 안전운전을 완전히 증명했다고 표현하지 않는다. 상위권에는 별도 추가 상품을 제공하며, 리그별 상품 배정과 공동 순위 처리는 시즌 시작 전에 공개한다.

경로 여권은 실제 다녀온 길과 방문 기록을 저장한다. 같은 경로의 반복 통과나 더 먼 거리 이동에 금전 보상을 누적하지 않는다. 첫 버전은 경로 수집 카드, 방문 배지와 공유 이미지로 구성하고, 테마별 기록장 꾸미기와 경로별 후기·질문·모임은 다음 단계로 개발한다. 공개 카드에는 집·직장 주변의 상세 경로와 정확한 이동 시각을 노출하지 않는다.

## 4 주요 사용 시나리오

### 직장인의 출퇴근

1. 주차 상태에서 앱을 설치하고 데이터 이용 범위를 선택한다. 기록을 공개하지 않고 개인 기능만 사용할 수도 있다.
2. 평소 출퇴근 경로를 등록한다. 앱은 필요한 차량 데이터와 경로 비교 조건의 지원 여부를 확인한다.
3. 운전 중에는 화면 조작 없이 기록한다. 초기 기준 기록이 쌓이는 동안에도 자신의 연비·전비와 경로 이력을 볼 수 있다.
4. 목적지에서 주차한 뒤 결과를 확인한다. 비교 가능한 기록이면 개인 기준 대비 변화와 같은 리그의 분포를 보여준다. 불충분한 기록은 순위 제외 이유를 설명한다.
5. 주말에 주간 순위와 미션 달성 여부를 확인한다. 완료한 미션의 경험치와 배지가 기록장에 추가되고, 등급이 오르면 프로필 테두리가 바뀐다. 기본 보상과 추가 상품은 별도의 공지된 조건으로 지급한다.

결과 화면의 예시는 ‘이번 경로 소비량 7.2L/100km, 내 기준 8.0L/100km 대비 10% 감소, 비교 조건 유사, 소요 시간 31분’이다. 이후 ‘이번 주 효율 지키기 완료 · 경험치 10점’과 획득 배지를 보여준다. 수치와 달성 장면은 화면 설명용 예시이며 실제 주행 결과가 아니다. 차이가 환경 때문일 수 있다는 점을 기록 조건과 함께 보여준다.

### 여행자의 경로 수집

여행자는 주차 후 다녀온 경로의 수집 카드를 열고 방문 배지를 여권에 붙인다. 공개 범위를 선택한 뒤 경로 카드로 공유한다. 해당 경로에 비교 가능한 기록이 충분할 때만 효율 리그에 참여한다. 여행 기록은 순위가 없어도 보관·공유할 수 있어 초기 사용자 밀도 부족을 완화한다.

### 데이터가 부족한 경우

연비·위치·제한속도 정보 중 필수 정보가 누락되면 결과를 ‘비교 보류’로 표시한다. 기록을 안전한 것으로 자동 인정하거나 추정값으로 상품 순위를 확정하지 않는다. 지원 범위에서 개인 경로 기록은 유지하고, 사용자에게 재주행을 요구하지 않는다. 이의제기는 주차 후 제출하며, 보상 확정 전에 검토한다.

## 5 개발 계획

### 구현 환경과 구성

Pleos Connect의 Android 환경에서 Kotlin으로 차량용 앱을 개발한다. 공식 개발 환경 안내는 Android API 28 이상과 Gradle 8.0 이상을 제시한다. 실제 프로젝트는 배포 대상과 SDK 호환 버전을 확인해 고정한다. [S3]

앱은 차량 데이터 수집, 지원 여부 확인, 경로 판정, 로컬 기록, 주차 후 결과 화면으로 구성한다. 서버는 계정·시즌·요약 기록·리그 집계·미션 상태·경험치·배지·보상 내역을 관리한다. 미션 달성은 사용자·시즌·주차·미션 ID로 중복 지급을 방지한다. 네트워크가 끊겨도 기록을 로컬에 저장하고 복구 후 중복 없이 동기화한다. 순위는 서버의 규칙 버전으로 다시 계산한다.

### 구간별 소비량 측정 전략

현재 주행 세션의 평균 연비는 임의의 짧은 도로 구간 소비량과 다르다. 평균값의 시작·종료 차이를 구간 소비량으로 사용하지 않는다. 초기 경쟁은 측정 세션의 시작·종료 경계와 등록 경로의 경계가 일치하고, 전체 주행의 효율을 유효하게 읽을 수 있는 기록으로 제한한다.

임의의 부분 구간 경쟁은 필요한 누적 소비량·주행거리 또는 충분한 해상도의 데이터가 제공되고 측정 정확도를 입증한 이후 추가한다. 순시 연비를 단순 평균하지 않으며 정차 중 소비, 회생, 단위 변환, 누락 구간을 포함한 계산을 검증한다. 지원되지 않는 경로에서는 개인 이동 기록을 제공하되 검증된 효율 순위를 생성하지 않는다.

### 제한속도 데이터 전략

NaviHelper의 CameraAlert에는 카메라 기준 제한속도와 과속 관련 필드가 있다. 이를 전체 도로의 제한속도 데이터로 간주하지 않는다. 전체 경로의 경쟁 자격을 검증하려면 지도 데이터 이용권한과 해당 구간에 적용되는 제한속도·시간 조건 등을 확보해야 한다. 처음에는 정보가 검증된 경로만 순위 경쟁에 사용한다. [S9]

공모전 시연은 에뮬레이터의 통제된 경로·속도·제한속도 시나리오로 정상 기록과 제외 기록을 보여준다. 실차에서 필요한 정보가 확보되지 않으면 공개 순위와 현금성 보상 기능의 출시를 보류하고, 해당 제한을 설명한다. 에뮬레이터에서 성공했다는 사실로 실차 전 구간의 검증을 주장하지 않는다.

### 첫 버전 범위

첫 버전은 차량 데이터 지원 확인, 선정 경로 자동 기록, 기록 자격 판정, 개인 결과, 한 개 경로의 시즌 보드와 주간 순위, 개인 미션 2종, 경험치·성장 등급, 기본 배지 3종과 보상 조건 표시로 구성한다. 첫 미션은 기준 기록 완성과 주간 효율 유지이며, 기본 배지는 첫 기준 완성·개인 기록 갱신·주간 대표로 정한다. 경로 여권은 방문 이력과 공유 카드까지 구현한다. 실제 기프티콘 발급은 운영자가 확정 내역을 검토한 뒤 처리하고, 시연 화면에는 발급 예정 상태를 표시한다.

자유 경로 생성, 차량 아바타·기록장 꾸미기, 팀 협동 미션, 보험사 연동, 자체 내비게이션과 대규모 커뮤니티 운영은 후속 범위다. 전국 통합 효율 순위와 주행 중 실시간 경쟁은 초기 서비스에 도입하지 않는다. 초기에는 SDK로 기존 차량 기능을 연결하고 핵심 기록 흐름을 완성한다.

### 검증 항목과 출시 조건

필수 검증은 정상 주행, 속도 초과, 제한속도 미확인, 센서 누락, 반대 방향, 경로 이탈, 세션 초기화, 중복 업로드, 네트워크 복구, 신호대기 중 화면 잠금, 미션 중복 지급 방지, 시즌 전환 시 누적 배지 보존이다. 각 시나리오의 입력과 예상 판정을 저장해 반복 확인한다.

경로 일치 판정은 정답 경로를 붙인 테스트 기록 50건 이상에서 확인하고, 정확도 95% 이상을 초기 개발 목표로 둔다. 속도 초과와 필수 데이터 누락이 있는 사전 정의 시나리오에서는 보상 자격 부여 오류가 0건이어야 한다. 이는 한정된 테스트 세트의 통과 기준이며 실제 도로에서 오류가 없다는 보장은 아니다.

효율값은 동일한 측정 경계의 기준 데이터와 비교해 오차 범위를 산정한다. 검증 오차를 정할 기준 데이터를 확보하지 못하면 정밀 구간 순위와 절감 효과 주장을 보류한다. 실제 배포는 데이터 권한, 주행 중 동작 정책, 지도 이용조건, 테스트 배포 권한과 앱 마켓 심사 조건 확인 후 진행한다.

## 6 기대효과와 사업 운영

### 사용자에게 제공하는 효과

출퇴근 운전자는 반복 경로의 변화를 자신의 기록과 비교하고, 주간 미션, 성장 등급과 기본 보상을 경험한다. 여행자는 경로 카드와 배지를 모으고 자신의 기록장을 공유한다. 연료·전력 절감은 실증할 성과 목표이며, 현재 달성된 효과나 보장 수치로 제시하지 않는다.

사용자 한 명만 있어도 개인 기록과 경로 여권이 제공된다. 비교 가능한 사람이 모이면 리그를 개설하는 방식으로 초기 사용자 부족에 대응한다. 실제 참여는 보상과 기록 자체의 동기가 함께 유지되는지 검증한다.

### 첫 3개월 운영 예산

최대 100명으로 제한한 시범 운영의 월 비용 상한은 50만원, 3개월 상한은 150만원으로 계획한다. 재원은 사전 확보한 팀 운영 예산을 전제로 한다. 해당 재원이 확보되지 않으면 금전성 보상 캠페인을 모집하지 않고 기록·배지 검증부터 진행한다. 가입 후 이미 공지한 보상 조건을 일방적으로 축소하지 않는다.

| 월 비용 항목 | 산정 방식 | 월 상한 |
| --- | --- | ---: |
| 기본 목표 달성 보상 | 최대 100명에게 각 2천원 | 200,000원 |
| 리그 추가 상품 | 최대 10개 상품에 각 1만원 상당 | 100,000원 |
| 서버와 지도 및 메시지 비용 | 테스트 규모의 비용 가정 | 100,000원 |
| 예비비 | 발급 수수료·운영 변동 대응 | 100,000원 |
| 합계 | 월 고정 상한 | 500,000원 |

위 금액은 견적이나 확정 지출이 아니다. 개발 인건비, 차량·기기 확보, 유료 지도 계약의 별도 최소 요금은 포함하지 않는다. 실제 견적이 상한을 넘으면 신규 모집 전에 규모와 데이터 구성을 조정한다. 추가 상품은 자격을 갖춘 리그에 시즌 시작 전에 배정하고, 대상이 없는 경우 예산을 소진하기 위해 임의 지급하지 않는다.

초기 보상은 조건 달성 시 지급되는 소액 보상을 중심으로 한다. 응모권은 기본 보상의 확실성을 낮출 수 있어 첫 실험의 중심에 두지 않는다. 후원 캠페인이 생기면 기존 기본 보상에 추가되는 선택 혜택으로 검토한다.

### 확보와 유지 목표

첫 20명 검증은 같은 생활권의 직장인과 차종별 커뮤니티에서 모집한다. 2주 동안 기준 기록과 사용성 문제를 확인하고, 이후 2주 동안 결과·목표·리그 경험을 관찰한다. 중단 사유와 보상이 없을 때도 남는 가치를 인터뷰한다. 20명 표본으로 시장 전체의 수요나 사고 감소 효과를 입증하지 않는다.

| 지표 | 정의 | 시범 운영 목표 |
| --- | --- | --- |
| 기록 활성화율 | 가입 후 7일 내 첫 유효 기록을 만든 사람 ÷ 가입자 | 70% 이상 |
| 4주차 유지율 | 첫 유효 기록 이후 22일부터 28일 사이 결과 조회·목표 설정 등 의도적 행동을 한 사람 ÷ 최초 활성화 집단 | 40% 이상 |
| 기록 유효율 | 지정 경로에서 비교 자격을 충족한 기록 ÷ 해당 경로의 전체 수집 기록 | 90% 이상 |
| 자발적 사용 | 금전성 보상 종료 후 2주 동안 미션·배지를 유지한 상태에서 결과 조회를 지속한 사람의 비율과 이유 | 비율 측정 후 확대 판단 |

| 에너지 변화 | 조건이 유사한 기준 기간과 사용 기간의 소비량 중앙값 및 변동 범위 | 측정 오차를 넘는 변화가 있는지 탐색 |

MAU는 최근 30일 동안 주차 후 결과 조회, 목표 설정 또는 경로 기록 공유를 한 고유 사용자 수로 정의한다. 자동 수집만으로 활성 이용자를 계산하지 않는다.

초기 3개월의 계획 시나리오는 지원 환경을 가진 사람 250명에게 도달하고, 100명 가입과 50명 MAU를 확보하는 것이다. 도달 대비 가입률 40%, 가입 대비 월 활성 비율 50%를 가정한 수치다. 확보된 사용자나 시장 조사 결과가 아니며, 첫 20명 결과로 수정한다. 지원 차량과 모집 채널이 확보되지 않으면 이 시나리오를 달성 전망으로 사용하지 않는다.

### 수익 구조와 제휴

기본 서비스는 무료로 제공하고, 초기 수익 후보는 충전·정비·세차 등 파트너의 캠페인 운영비다. 파트너에게는 동의를 받은 참여·혜택 사용의 집계 결과를 제공하고, 캠페인의 추가 방문·이용 전환을 검증한다. 개인의 상세 이동 경로 판매를 초기 수익모델로 두지 않는다.

제휴 수익은 계약 전에는 매출로 계산하지 않는다. 유료 캠페인 확대 조건은 캠페인 매출이 보상 원가·발급비·추가 운영비를 충당하고, 보상 종료 뒤에도 사용이 유지되는 것이다. 일시적인 쿠폰 수령만 늘어나는 경우 비용을 늘리기보다 제품의 반복 사용 가치를 수정한다.

현대해상에는 커넥티드카와 티맵 등의 안전운전 할인특약이 존재한다. 이는 데이터 기반 혜택의 사례이며 이 서비스와의 제휴를 의미하지 않는다. 보험 제휴는 운전자 식별, 누락·선별 기록 방지, 사고 위험 예측에 대한 추가 가치 검증 후 협의한다. 효율 순위를 보험료 할인 자격으로 바로 전환하지 않는다. [S11]

### 확장 순서

| 단계 | 확장 내용 | 다음 단계로 가기 위한 조건 |
| --- | --- | --- |
| 1단계 | 반복 경로의 개인 기록과 조건별 리그 | 데이터 접근, 측정 범위, 사용자 재방문 확인 |
| 2단계 | 여행 경로 여권과 경로별 커뮤니티 | 기록·공유의 자발적 사용, 신고·운영 체계 확보 |
| 3단계 | 제휴 캠페인과 기업·동호회 단위 리그 | 운영비 충당과 참여 지속성 검증 |
| 4단계 | 차량·내비게이션 분석과 보험 제휴 연구 | 데이터 이용 동의, 충분한 표본, 구매자의 추가 가치 확인 |

차량 개선에는 단순 효율 수치보다 경로 조건, 사용자 목표, 피드백 이후의 변화가 결합된 분석을 제공하는 방향을 검토한다. 홍보용 리포트는 최고 기록만 선택하지 않고 측정 조건·표본 수·분포를 함께 제공한다. 내비게이션 분석은 통행량 대비 반복 속도 변화 등 검토가 필요한 구간의 패턴을 연구하며 사고 위험을 단정하지 않는다. 보험과 제조사 활용은 각각 별도의 검증·계약 과제로 추진한다.

## 7 개인정보와 기록 신뢰성

개인 기록 사용, 커뮤니티 공개, 제휴·연구 활용의 목적과 선택을 구분한다. 공개 공유나 추가 데이터 제공에 동의하지 않아도 개인 기록 기능을 사용할 수 있도록 설계한다. Pleos의 개인정보 가이드에 따라 최소 권한, 이용 목적, 보유 기간, 제3자 제공 범위와 철회·삭제 경로를 명시한다. 위치정보를 이용한 서비스 운영에 필요한 조건은 실제 출시 전에 별도로 확인한다. [S12]

초기 보관 설계는 원시 위치·속도 기록의 차량 내 보관을 최대 30일로 제한하고, 서버에는 경로 ID·조건·요약 수치·자격 판정 근거를 우선 저장하는 방식이다. 서버의 운영 요약은 시범 운영 목적에 맞춰 기본 90일 보관 후 삭제 또는 개인 식별이 어려운 집계로 전환한다. 가명 ID만 붙인 경로를 익명 데이터라고 간주하지 않는다. 이용자가 보관하기로 선택한 개인 경로 여권은 별도 설정과 삭제 기능을 제공한다.

순위 조작 대응은 차량 세션·거리·위치·시간의 일관성 확인, 중복 방지, 기준 기록 고정, 규칙 버전 기록, 비정상 기록 검토로 구성한다. 서명과 무결성 검사만으로 차량 데이터의 진위를 보장할 수 없으므로 초기 보상은 소액·제한 규모로 운영한다. 앱을 끄거나 기록 일부를 제출하지 않은 경우 이를 보완 가능한 항목과 검증 불가 항목으로 나누고, 검증 불가 기록에는 보상 자격을 부여하지 않는다.

공유 차량에서는 주차 상태의 프로필 선택을 제공하되 실제 운전자 확인을 완전히 보장한다고 주장하지 않는다. 개인 수준의 보험 판단에 활용하려면 별도 식별과 검증 체계가 필요하다. 보상 판정의 이의제기 기간은 결과 공지 후 7일로 두고, 개인정보 접근 범위를 제한한 운영 절차로 처리한다.

## 8 제출 자료와 발표 구성

공식 접수양식에는 서비스 소개, 기획 배경, 주요 기능, 사용 시나리오, 개발 계획, 기대효과를 해당 작성란에 옮긴다. 참가자의 이름·연락처·소속은 운영 접수용 영역에만 기재하고 작품 소개 자료에는 넣지 않는다. 개인 또는 팀 정보와 각 참가자의 동의·서명은 제출자가 직접 완성한다. [S1]

제출 산출물의 목표는 실행 가능한 APK, 소스 코드, 실행 방법을 담은 README, 60초에서 90초 분량의 핵심 시연 영상이다. 이 문서 작성 시점에는 해당 개발 산출물과 링크가 준비되어 있지 않으며, 개발 완료 후 실제 링크를 기재한다. 숏폼은 선택 자료로 제작 여부를 별도 결정한다.

시연 영상은 ‘주차 상태의 경로·시즌 선택 → 자동 기록 → 주차 후 결과와 순위 공개 → 미션 완료·배지 획득 → 기본 보상 확인 → 데이터 누락 또는 속도 초과 기록의 제외’ 순서로 구성한다. 시뮬레이션 장면에는 에뮬레이터 데이터임을 표시한다. 실제 구현 화면, 설명용 화면, 향후 기능을 명확하게 구분한다.

발표에서는 고객이 겪는 반복 경로의 문제, 차량 데이터가 필요한 이유, 실제 동작, 공정한 비교의 범위, 재사용 검증과 보상 운영 순서로 설명한다. 개발 산출물은 1차 가산점 대상이며 2차 PT 전까지 동작하는 앱이 필요하다. [S2]

| 공식 1차 심사 항목 | 기획서의 대응 내용 | 시연 또는 검증으로 제시할 근거 |
| --- | --- | --- |
| 차량특화성 | 실제 차량 효율과 경로·주차 맥락의 결합 | 차량 데이터 수집과 주행 중 화면 제한 |
| 창의성 | 조건별 시즌 리그와 개인 미션·성장 등급·경로 수집의 연결 | 한 경로에서 개인 변화와 리그 결과를 함께 보여주는 흐름 |
| 기술 활용성 | Vehicle·FusedLocation·NaviHelper와 AAOS 활용 | API별 입력, 정상 동작, 미지원·누락 처리 |
| 사업성 | 초기 고객·확보 계획·운영 예산·유지율 정의 | 20명 검증 결과와 보상 비용, 제휴 전후 운영 구조 |

공식 배점은 공개되어 있지 않으므로 항목별 예상 심사 점수는 기획서에 제시하지 않는다. [S2]

## 9 심사 질문에 대한 핵심 답변

**왜 스마트폰 앱이 아니라 차량용 앱이어야 하는가**

차량이 제공하는 연비·전비와 주행 세션을 경로 기록에 결합하고, 주행·주차 맥락에 따라 자동 기록과 결과 확인을 분리한다. 실제로 확보한 차량 데이터가 개인 비교와 리그의 기준이 되는 것을 시연한다.

**기존 구간 경쟁과 무엇이 다른가**

Strava에도 구간별 기록 비교와 순위가 있다. 이 서비스의 차별점은 차량 환경에서 속도 보상을 배제하고, 에너지 효율과 측정 조건에 기반한 시즌 리그, 개인 미션과 배지 수집을 결합하는 것이다. 최초의 경로 경쟁이라는 주장은 하지 않는다. [S13]

**좋은 차를 가진 사람이 유리하지 않은가**

차종과 동력계가 다른 기록을 하나의 절대 효율 순위로 섞지 않는다. 비교 집단이 부족한 초기에는 개인 기준 대비 피드백을 제공한다. 남는 조건 차이는 표시하고 과도한 정밀 순위를 만들지 않는다.

**효율만 높이면 안전운전이라고 볼 수 있는가**

효율과 안전을 별도로 다룬다. 확인 가능한 속도·데이터 조건으로 경쟁 자격을 판단하지만 모든 위험 행동을 판별하지는 못한다. 주행 중 경쟁 자극을 제거하고, 안전을 해치는 효율 향상 방법을 안내하지 않는다.

**보험사와 제휴하지 못하면 서비스가 유지되는가**

초기 제품의 가치는 개인 기록, 목표 달성, 경로 여권이다. 보상은 사전에 확보한 제한 예산으로 운영하고 보험 제휴를 제품 출시 조건으로 두지 않는다. 금전성 보상 종료 이후에도 미션·배지를 유지하고 자발적 결과 조회를 별도로 측정한다.

**아직 사용자가 적은데 누구와 경쟁하는가**

같은 생활권과 유사 차종 중심으로 모집해 비교 집단을 만들고, 조건을 충족한 경로에서만 리그를 연다. 충분한 사람이 모이기 전에도 개인 비교와 기록 기능을 사용할 수 있다.

**데이터 수집이 제조사에 어떤 새 가치를 주는가**

제조사가 가진 데이터와의 중복 여부를 먼저 확인한다. 사용자 목표와 피드백 반응, 경로 조건별 변화처럼 추가되는 정보의 가치가 확인될 때 제휴 분석을 제안한다. 데이터가 쌓인다는 사실만으로 매출이나 차량 개선 효과를 주장하지 않는다.
